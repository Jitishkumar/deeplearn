### 5. Technical Deep Dive (3 minutes)

**Show Some Code (prepare screenshots):**

**1. ML Prediction Function:**
```python
def predict_failure(
    files_changed: int,
    lines_changed: int,
    test_coverage: float
) -> Dict:
    """
    Predict build failure using ML model
    """
    features = [files_changed, lines_changed, test_coverage]
    
    if self.model:
        probability = self.model.predict_proba(features)[0][1]
    else:
        # Heuristic fallback
        probability = self._heuristic_prediction(features)
    
    return {
        "will_fail": probability > 0.7,
        "failure_probability": probability,
        "risk_level": self._get_risk_level(probability)
    }
```

**Explain:**
- "The ML model uses Random Forest algorithm
- Features include: files changed, code complexity, test coverage
- Has a heuristic fallback for cold start
- Returns actionable predictions"
